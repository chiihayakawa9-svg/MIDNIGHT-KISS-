MIDNIGHT KISS ―真夜中の秘密― 悠真ルート体験版

GitHub Pagesで公開する方法
1. GitHubでリポジトリを開く
2. Add file → Upload files で、このフォルダ内の全ファイルをアップロード
3. Commit changes
4. Settings → Pages → Deploy from a branch → main / (root) → Save
5. 数分後、表示されるPages URLを開く

iPhoneでアプリのように使う
1. 公開URLをSafariで開く
2. 共有ボタン → ホーム画面に追加

機能
- 主人公名の自由入力
- 悠真ルートの選択肢と好感度
- 好感度によるエンディング分岐
- ローカル保存／ロード
- PWA対応（HTTPSで公開した場合）

画像について
